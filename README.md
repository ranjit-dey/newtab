# New Tab — Minimal, Serene & Customizable Dashboard 🌌

A clean, modern, and human-crafted new tab extension built with authentic frosted glassmorphism, responsive design, and native Web APIs (Manifest V3 compatible with Chrome, Brave, Edge, Arc, and Opera).

---

## ✨ Features

- **🎨 22 Curated 4K Wallpapers & Solid Colors**:
  - High-definition atmospheric landscapes (*Alpine Peaks, Misty Redwoods, Nordic Cascade, Sahara Twilight, Glacial Reflection, Mount Fuji*).
  - Deep space vistas (*Deep Nebula, Earth Atmosphere, Milky Way Ridge, Solar Corona*).
  - Cyberpunk & urban dusk (*Shinjuku Rain, Shanghai Dusk, Neon Backstreet*).
  - Minimalist architecture & 3D flow (*Bauhaus Shadows, Kyoto Pavilion, Nordic Solitude, Slate Topography, Fluid Chrome, Velvet Gradient*).
  - **8 Solid Color Themes** (*OLED Black, Space Slate, Midnight Navy, Charcoal, Deep Emerald, Velvet Plum, Warm Espresso, Light Pearl*) + live **Hex Color Picker**.
  - Custom local image upload with live blur and brightness sliders.
- **⚙️ Power-User Preferences & Control Center Window**:
  - Replaces narrow sidebars with a full-window preferences dashboard (940px modal with sidebar tabs).
  - Comprehensive control: Wallpapers & 4K, Solid Colors, Clock Typography, Pomodoro Durations, Search Engines, Widget Visibility, and JSON Backup/Restore.
- **⏱️ Upgraded & Customizable Pomodoro Focus Timer**:
  - Customizable focus durations, short breaks, and long breaks (e.g. 50m / 10m / 20m).
  - Quick adjustment buttons: `-5m`, `-1m`, `+1m`, `+5m` directly in the timer.
  - Daily Pomodoro streak counter (*"X focus sessions completed today"*).
  - 4 customizable completion chimes (*Zen Singing Bowl, Classic Double Bell, Deep Gong, Digital Tech Chime*).
  - Auto-start next session toggle.
- **⏰ 5 Clock Styles with Smooth macOS Slide-Up Transitions**:
  - *macOS Minimal*, *Glass Capsule*, *Cyber Monospace*, *Editorial Serif*, and *Bento Stack*.
  - When minutes change, the old number slides up and fades out while the new number slides in smoothly from below.
- **🔽 Clean Left-Aligned Custom Dropdowns**:
  - Replaced browser system dropdowns with clean, frosted glass popovers with left-aligned labels, icons, and active checkmarks.
- **💡 Built-in Tip to Hide Chrome's Native Bottom Bar**:
  - Includes a dismissible helper tip explaining how to remove the native Chrome bottom bar (`New Tab` & `Customise Chrome`) with a single right-click.
- **🎧 Ambient Procedural Soundscapes**:
  - Web Audio API synthesizer for *Gentle Rain*, *Ocean Waves*, *Campfire Crackle*, and *Focus Noise* with volume control.
- **🌤️ Live Weather Widget**:
  - Free Open-Meteo API integration with automatic geolocation and searchable cities worldwide.
- **✅ Daily Tasks & Scratchpad**:
  - Clean tasks checklist popover with filter tabs (*All*, *Active*, *Done*) and unread counter badge.
  - Auto-saving scratchpad notes with word and character counters.
- **🔍 Omni Search Bar**:
  - Google, DuckDuckGo, Bing, Brave, Perplexity, YouTube, GitHub, Reddit.
  - Voice search and keyboard shortcut (`/` to focus).

## 🚀 How to Install in Your Browser

1. Open your browser and navigate to:
   - **Chrome / Brave**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
   - **Opera**: `opera://extensions/`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click the **Load unpacked** button in the top-left corner.
4. Select the project folder:
   ```text
   /Users/ranjitdey/Dev/newtab
   ```
5. Open a new tab (<kbd>Cmd</kbd> + <kbd>T</kbd> / <kbd>Ctrl</kbd> + <kbd>T</kbd>)!

---

## 💡 How to Permanently Remove the Chrome Footer
Right-click directly on the bottom bar containing `New Tab` & `Customise Chrome`, then click **"Hide footer on New Tab page"**.
